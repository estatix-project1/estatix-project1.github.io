**この記事のまとめ(150字)**:
Claude Code は非エンジニアでも日本語だけで使える AI エージェントです。準備は Anthropic のアカウント作成のみ、基本の使い方は「動詞+対象+条件」で指示するだけ。特別な PC も英語力も不要で、無料枠から試せます。この記事では、最初の 30 分でやることを順番に紹介します。

## Claude Code とは何か(ChatGPT との違いを1行で)

Claude Code は、米 Anthropic 社が提供する AI アシスタントの「実行できる版」です。ChatGPT が「質問に答える」ツールだとすれば、Claude Code は「指示された作業をパソコン上で実際にやってくれる」ツール、と覚えておくと感覚がつかみやすいです。

技術者向けの機能もありますが、日本語で「◯◯というファイルを作って」「この文章を読みやすく直して」と話しかけるだけで動くため、非エンジニアでも十分に使えます。

## 準備するもの(3つだけ)

始めるのに必要なのは次の 3 つです。

- **インターネットにつながる PC**(Mac / Windows どちらでも可。特別な高スペックは不要)
- **メールアドレス**(Anthropic のアカウント登録に使用)
- **クレジットカード**(有料プランを使う場合のみ。無料の試用範囲だけなら不要)

よく誤解されますが、以下は **必要ありません**。

- 英語力(日本語のみで完結します)
- プログラミング経験(コードを書けなくても指示だけで動きます)
- 高性能な PC(一般的なノート PC で十分)

## アカウントを作る(5ステップ)

1. Anthropic の公式サイトにアクセスし、「Sign Up」からメールアドレスを入力
2. 届いた認証メールのリンクをクリック
3. 表示名と用途(個人利用など)を選択
4. 利用規約に同意して登録完了
5. ログイン後、Claude Code の案内ページから利用開始

登録自体は 5 分程度で終わります。無料の試用枠内であれば、この時点で最初の指示を試せます。

## 最初の指示は「動詞+対象+条件」で書く

Claude Code に何かをさせるとき、思いつきの一言では期待どおりに動かないことがあります。以下の 3 要素を意識するだけで、結果が大きく変わります。

- **動詞**: 何をしてほしいか(作って / 直して / まとめて など)
- **対象**: どのファイルやどのテキストか
- **条件**: 何字以内で、どんな口調で、といった制約

たとえば「文章を良くして」ではなく、「以下の 300 字の自己紹介文を、初対面のビジネス相手向けに、丁寧語で、200 字以内にまとめ直して」と伝えると、返ってくる質が段違いに上がります。

## 最初の 30 分でやることプラン

登録直後の 30 分を無駄にしないための手順です。

| 時間 | やること |
|---|---|
| 最初の 10 分 | 手元の短い文章(自己紹介・お知らせ文など)を渡して「読みやすく直して」と依頼 |
| 次の 10 分 | 上の要領で条件を追加し、複数パターンを出させて比較する |
| 最後の 10 分 | 今日試したやり取りを 1 つ、自分の言葉で「使い方メモ」として書き残す |

小さな成功体験を 1 つ作れば、翌日以降の活用イメージが一気に具体的になります。

## 安全に使うための 3 つのコツ

Claude Code は便利ですが、AI ゆえの弱点もあります。次の 3 点だけ最初に押さえてください。

- **大事なファイルはコピーを分けておく**:AI に触らせる前に、元ファイルは別名で残す
- **実行前にひと呼吸**:AI が提案した内容が、自分の意図と合っているか目視で確認してから採用する
- **重要情報の断定は自分で確認**:数字・日付・固有名詞は必ず一次情報で裏取りする

この 3 つは、業種を問わずすべての AI 利用に共通する基本ルールでもあります。

## よくある質問(FAQ)

**Q. 無料で使えますか?**
A. Anthropic の無料試用枠内であれば無料で試せます。継続的に使う場合は有料プランの検討が必要になります。

**Q. 英語ができないと使えませんか?**
A. いいえ。日本語での指示・回答に対応しています。

**Q. プログラミングの知識がなくても大丈夫ですか?**
A. 大丈夫です。文章の整理、資料作成の下書き、リサーチの要約など、コードを書かない用途で十分に活躍します。

**Q. 情報は外に漏れませんか?**
A. Anthropic のプライバシーポリシーに従って扱われます。ただし機密情報や個人情報は、AI に渡す前に匿名化するのが基本です。
